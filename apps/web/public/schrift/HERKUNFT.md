# Schriften

`archivo-latin.woff2` ist Archivo Variable (Achsen `wdth` 62–125 und `wght` 100–900),
auf den Latin-Subset beschnitten, geladen von Google Fonts (v25).

`../assets/archivo-400.woff` und `../assets/archivo-700.woff` sind statische Instanzen
derselben Familie. Sie werden nicht im Browser geladen, sondern nur serverseitig für
das Vorschaubild (`opengraph-image`), weil Satori kein woff2 liest.

Archivo steht unter der SIL Open Font License 1.1.
Urheber: Omnibus-Type. Quelle: https://fonts.google.com/specimen/Archivo
